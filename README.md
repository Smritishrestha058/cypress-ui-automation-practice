## Cypress UI Automation Practice
This project contains beginner-level UI automation testing using Cypress.

## Website Tested
https://trytestingthis.netlify.app/

## Tools used
- Cypress
- JavaScript
- Node.js

## Test Scenarios
- Page Load Validation
- Handling browser confirm popups (OK / Cancel)
- Double-click interactions
- Drag and Drop Functionality
- Login Form Testing with valid and invalid credentials

## How to run
1. Clone the repository
2. Run `npm install`
3. Run `npx cypress open`
